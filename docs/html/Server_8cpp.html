Detailed Description

Implements the Server class for managing an IRC server.

Implements the Server class, which owns the listening socket, tracks connected clients and channels, and dispatches network events and client commands. The server uses poll() to monitor multiple sockets for incoming and outgoing data, and handles new connections, client input, and output in a non-blocking manner.
