Detailed Description

Manages the IRC server and its client connections.

Owns the listening socket, tracks connected clients and channels, and dispatches network events and client commands.

Destroys the Server instance and cleans up resources.

void Server::mainLoop ( )
private

Runs the server's main event loop.

Waits for activity on the listening socket and connected clients, then dispatches the corresponding input and output handlers.

Warning
This method blocks indefinitely and does not return under normal operation.

◆ start()

void Server::start ( )

Initializes the listening socket and starts the event loop.

Creates an IPv4 stream socket, binds it to the configured port, registers it with poll(), and listens for incoming connections.

Exceptions
UnknownExceptionIf an unknown socket, bind, or listen error occurs.
NotEnoughPermissionsExceptionIf the process lacks the required permissions.
NotEnoughMemoryExceptionIf the system cannot allocate the required resources.
NotEnoughFileDescriptorsExceptionIf no file descriptors are available.
UnsupportedIPProtocolExceptionIf IPv4 sockets are not supported.
PortInUseExceptionIf the configured port is already in use.
InvalidFileDescriptorExceptionIf a socket file descriptor is invalid.
AlredyLinkedFileDescriptorExceptionIf the socket is already bound.
FileDescriptorIsNotSocketExceptionIf the file descriptor is not a socket.
SocketNotSupportListenExceptionIf the socket does not support listening.
