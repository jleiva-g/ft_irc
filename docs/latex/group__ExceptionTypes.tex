\doxysubsection{Detailed Description}
Custom exception types for the IRC server. 

This group contains the {\ttfamily \mbox{\hyperlink{structPersonalizedException}{Personalized\+Exception}}} base class and several derived exception types that represent specific error conditions encountered during server operation. Each exception type carries the source file and line number where it was thrown, allowing for detailed error reporting and debugging.
