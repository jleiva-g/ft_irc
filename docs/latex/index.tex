A simple IRC server implementation in C++. This project implements a basic IRC server that supports multiple clients and channels. The server uses non-\/blocking sockets and the {\ttfamily poll()} system call to handle multiple connections concurrently. It provides a command interface for clients to join channels, send messages, and manage their connections.
